# Before you start: the first-run notice

The first time you open Bottle, the hub shows the notice "Before you start".
The notice has a version number.

1. Read the notice.
2. Check "I read this notice. I will get consent before I record other people."
3. Select Continue.

Continue stays off until you check the box.
Bottle does not record before you accept the current version of the notice.
When the notice changes, Bottle shows the new version again before the next recording.

Bottle keeps a local record of each version that you accepted, with the time and a device ID.
The record holds no audio and no text of what you said.
Bottle keeps this record in its encrypted local store, on this device only.
Bottle keeps each record for 13 months.
When Bottle has no record of the current version, Bottle shows the notice again.

If Bottle cannot open its local store, Bottle cannot keep the record.
Then the notice stays open, and Bottle does not record.
