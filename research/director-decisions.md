## Round 2 reconciliation (D27-D52)
- D27 Canonical stop-policy values are D5. Architect defaults softCapMin 90 / hardCapMin 240 are replaced by softCapMin 60, extendMin 30, checkInAtMin 55, silenceNudgeMin 5, silenceStopMin 15, hardCapMin 240 (admin 60-480), pttMaxMin 5.
- D28 Canonical backend enum everywhere (TS, config schema, DDL): genie_one_mcp | genie_agent | custom_agent. genie_agent has mode chat (v1) | agent_mode (v2). Excluded as backends: per-space Genie MCP, Genie One API SSE. Genie One API may be used only as a utility (conversation delete/list) if the spike passes.
- D29 Context caps: preamble <= 800 chars, <= 5 items, each <= 160 chars; user question <= 1,000 chars after sanitising; whole message <= 2,000 chars; byte guard 25,000 UTF-8 bytes. Header text: "Context (from my notes, may be wrong):" then "- item" lines then "Question: ...". Sent on the first turn of a conversation, or later only with new items. Same-workspace items only unless share_context_cross_workspace (default off; MDM can forbid). Only You-track or user-confirmed items. On POLICY_DENIED retry once without the preamble.
- D30 Thresholds: PTT/hands-free question with confidence >= 0.7 -> 1.5 s preview -> send; < 0.7 -> chip. Session: chip at >= 0.7; opt-in auto-ask at >= 0.8, <= 1 per 2 min per MOG, You-track only, injection_suspected=false, no split.
- D31 Genie One MCP polling: polling path only (never _meta.progressToken); serial per conversation; delay from end of previous poll: 2 s (0-20 s), 3 s (20-60 s), 5 s (60-180 s), then x1.5 capped 15 s; +-10% jitter. Soft notice 4 min, hard give-up 10 min, late re-polls at +15 and +60 min. Shared per-profile token bucket default 40 calls/min (polls first, then cancels, then new asks), AIMD after 429. Concurrency <= 2 in-flight asks per MOG, <= 4 per profile, 1 per conversation.
- D32 Tauri >= 2.12.5: macOSPrivateApi is NOT required for transparency (architect ARC-7 corrected). Distribution: signed, notarized DMG (macOS) and signed MSIX/NSIS (Windows). Mac App Store not targeted. Rive web runtime @rive-app/webgl2 or @rive-app/canvas (spike decides); never the deprecated @rive-app/webgl.
- D33 Bridge split (refines D2): Rust owns CLI runs, token cache, host allowlist, HTTP/MCP transport, in-flight poll guard, secret scrubbing. The hidden TS "brain" window owns tool contracts, error-to-user-text mapping, conversation pinning, routing. No token, Lakebase password or SQLCipher key crosses IPC. Rust exposes fixed statement catalogs for SQLite and Lakebase.
- D34 Lakebase: per-user project in the home workspace created by the app at 0.5-2 CU, 900 s suspend, PITR 2 days, tags app=mother-bricks/owner; pooled shared project (per-user role + FORCE RLS) is a v1 admin mode. Rust pool: direct TLS (no PgBouncer), max 3 connections, idle timeout 300 s, max lifetime 50 min, new credential per new connection, prewarm SELECT 1 at app start and on hotkey key-down. MVP works on pgvector (HNSW + GIN); lakebase_ann after the admin enables Lakebase Search (irreversible, restarts computes). If Lakebase is unavailable or port 5432 is blocked: local-only memory mode with a badge.
- D35 Embeddings: default databricks-qwen3-embedding-0-6b at 1024 dims (local cache 256-d MRL f16); fallback and admin-forced-GA option databricks-gte-large-en at 1024 dims (local cache full 1024-d f16, capped at 10k items). embedding_model column per row; re-embed on change. Offline recall = local FTS5 + recency only.
- D36 Retention (final): local dictation history 7 d; local transcripts 30 d; session audio deleted <= 5 min after transcript commit (<= 24 h if commit fails); Lakebase memory_item 180 d sliding on last_seen (pinned: none); Lakebase session 180 d; genie_exchange 90 d; opt-in remote utterances 30 d; consent records 13 months; Genie conversations created by Mother Bricks deleted after 90 d where an API allows (genie_agent: GA DELETE; Genie One: only if the spike shows the Genie One API can delete MCP threads, else "delete in Genie One" deep link). PITR 2 d disclosed in UI. MDM MemoryRetentionDays default 180 (not 0=forever). Admin policy overrides user settings. [confirm]
- D37 Cross-workspace answers: full answer content goes to Lakebase only when the Genie workspace equals the home Lakebase workspace; otherwise Lakebase stores a pointer (ids, deep link, topic, host), unless user opt-in AND MDM CrossWorkspaceAnswerStorage. Local encrypted cache keeps full content 30 d. Answer-from-memory only for same workspace and space and age <= 24 h.
- D38 Model defaults (config values, eval-gated): cleanup databricks-meta-llama-3-1-8b-instruct; router: same small model with strict json_schema if verified, else databricks-gemini-3-1-flash-lite; memory writer databricks-gpt-oss-120b (fallback Llama 8B); recall judge Llama 8B; ASR system.ai.gemini-3-1-flash-lite via Unity Gateway (needs cross-geo routing), candidates gemini 3.5 Flash / 4 Carbon for residency.
